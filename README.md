# Comedogenic ingredients list (Fulton 1989)

Comedogenic and irritancy grades (0 to 5) for 219 cosmetic ingredients, transcribed from:

> Fulton JE Jr. [Comedogenicity and irritancy of commonly used ingredients in skin care products](https://library.scconline.org/v040n06/13). *Journal of the Society of Cosmetic Chemists* 40(6):321-333 (1989). Rabbit ear model. Background on how the grades are used today: Draelos ZD, DiNardo JC, *A re-evaluation of the comedogenicity concept*, J Am Acad Dermatol 2006 ([PubMed 16488305](https://pubmed.ncbi.nlm.nih.gov/16488305/)).

Browse and filter it at **https://shehrii.github.io/comedogenic-ingredients/**, or check a full product label with the free [pore-clogging ingredient checker](https://heyskin.app/pore-clogging-ingredient-checker/) from [Hey Skin](https://heyskin.app/).

## Files

- `comedogenic-ingredients.csv` and `comedogenic-ingredients.json`, one row per ingredient.

| Column | Meaning |
| --- | --- |
| ingredient | Ingredient name as in the source table |
| comedogenic_grade | 0 (none) to 5 (severe); ranges and starred values are kept as printed |
| irritancy_grade | 0 to 5 surface irritation |
| tier | high (4 to 5), moderate (3), low-moderate (2), low (0 to 1) |
| group | Fulton's ingredient group |
| source_page | Page of the journal table |
| note | Context from the paper where it changes the reading |

## Caveats

Rabbit ear skin reacts more strongly than human skin. Fulton notes that grades varied with the supplier and grade of each raw material and with the concentration in the finished product. Use the grade as a reason to look closer, not as a verdict on a product.
