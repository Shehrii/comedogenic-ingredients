Comedogenic ingredients list

Comedogenic (pore-clogging) and irritancy grades on a 0 to 5 scale for 219 cosmetic ingredients, transcribed from James E. Fulton Jr., Comedogenicity and irritancy of commonly used ingredients in skin care products, Journal of the Society of Cosmetic Chemists (1989) 40(6), pages 321 to 333, using the rabbit ear model. The page number of the source table is in the CSV.

Download: CSV · JSON · GitHub repository

To check a whole product label against this list, paste it into the free pore-clogging ingredient checker by Hey Skin, which this dataset was built for.

Read the grades with care. They come from rabbit ears, which react more strongly than human skin, and Fulton notes that results depended on the supplier and grade of each raw material and on the concentration in the finished product. A high grade means "worth checking if you break out", not "this product will clog pores".
